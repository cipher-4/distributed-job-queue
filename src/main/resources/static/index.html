Architecture Highlights

Production Ready
  • Atomic Worker Leases: Uses SELECT ... FOR UPDATE SKIP LOCKED to prevent worker contention and race conditions.
  • Crash-Resilience: If a worker crashes mid-task, the visibility lease expires and the zombie reaper reclaims it automatically.
  • Exponential Backoff: Retries with capped exponential formula base × 2^(retry-1) before routing to DLQ.
  • DLQ Replay Engine: Isolates permanently failing tasks for manual inspection and zero-loss replay.
  • Strict Idempotency: Ensures partial job crashes never double-charge or duplicate external side effects.
